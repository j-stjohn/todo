# Todo List CLI Readme

Welcome to the a CLI Todo List tool called todo.c

## Overview

Todo is a CLI tool for task management, designed as a C learning project

## Features

- Create task list files
- Add tasks into the task list file created
- View tasks
- Append tasks

## Requirements

- Compiled with GCC and C99 standards
- Make
- Linux/Unix-like Operating 

### Building

To build the cli tool, you just compile the source code, `make`

## Usage

```BASH
./todo
```
